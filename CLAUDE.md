# CLAUDE.md

Portfolio site: Next.js App Router, TypeScript, static export (`output: "export"`), React Three Fiber + GLSL for the
contour field, Motion (and Motion+) for springs and gestures, React `<ViewTransition>` for route morphs. npm only.

## Commands

- `npm run dev` — dev server plus the local endpoint the dev-only tuning panel saves through
- `npm run build` — static export to `out/` (set `NEXT_PUBLIC_BASE_PATH=/<repo>` to mimic GitHub Pages)
- `npm run preview` — serve `out/` like a static host (honours `NEXT_PUBLIC_BASE_PATH`)
- `npm run lint` · `npm run typecheck` · `npm run check:contrast` · `npm run report:size`
- `npm run terrain` — regenerate `public/terrain` from swisstopo data (downloads ~100 MB once into a git-ignored cache)

Installing needs `MOTION_TOKEN` in the environment (see README). Never write the token into a file.

## Structure

- `src/app` — routes (`/`, `/work/[slug]`), root layout, global CSS
- `src/components` — `terrain/` (contour field), `card/` (Summit Card, deck), `transition/`, `hud/`
- `src/content` — all copy and card data (`cards.ts`, `site.ts`); components never hardcode copy
- `src/styles/tokens.ts` — design tokens
- `src/config` — committed tuning values written by the dev panel
- `scripts/` — Node scripts only (must run on Windows, macOS and Linux)
- `public/terrain` — generated by `npm run terrain`, committed

## Rules

- Tokens are the single source of truth: colours, type, durations, easings and springs come from
  `src/styles/tokens.ts` (exposed to CSS as custom properties). Don't hardcode values that exist as tokens.
- Every runtime asset URL that doesn't go through `next/link` or `next/image` (textures, terrain SVGs, fetch calls)
  must use `asset()` from `src/lib/asset.ts`, or it breaks under the GitHub Pages sub-path.
- Accessibility: semantic HTML first, content readable without JavaScript, keyboard operable, WCAG AA contrast
  (on the sheet colour only sheet-ink, moss-ink, alpenglow-ink or ground).
- Motion: every effect needs a reduced-motion twin (`prefers-reduced-motion` or the in-site Calm map toggle,
  exposed as `html[data-motion="reduced"]` and `useReducedMotion()`).
- Keep heavy code out of the initial bundle (Three/R3F and Motion load lazily) and keep transfer per visit small.
- Next.js docs for the installed version live in `node_modules/next/dist/docs/`.
